A status is a word plus a color plus an icon, on its soft ground. Five statuses: `verified` (good), `blocked` (bad), `pending` (warn), `sponsored` (good, the zap icon, for a gas-sponsored transaction), `agent` (brand, for a KYA market-maker quote).

Pass `status`; the default label is the Spanish word. Pass children to change the word, never to remove it. Place the pill at the end of a row or in the sheet header, one per item. Do not use a pill as a button.
