The action button in four variants. `primary` is the one filled indigo button on a screen: the sale, the signature. `secondary` is an indigo outline for the other path. `ghost` is tracked text with a small arrow, for low-stakes actions. `danger` is a `bad` outline, for revoke and cancel only.

Labels are verbs in the user's words: "Sell 4 tokens", "Cancel order". Pass `size="lg"` for the full-width confirm button (56px). Disabled buttons get a dashed outline and keep their label; put the reason in a `caption` beside them. Pass `busy` while signing: it blocks clicks and shows a dashed working state. Never two `primary` buttons on one screen.
