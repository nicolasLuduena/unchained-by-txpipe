The action button in four variants. `primary` is the one amber fill on a screen: the sale, the signature. `secondary` is a buff outline for the other path. `ghost` is underlined text for low-stakes actions. `danger` is a `bad` outline, for revoke and cancel only.

Labels are verbs in the user's words: "Vender 4 tokens", "Cancelar orden". Pass `size="lg"` for the full-width confirm button (56px). Disabled buttons get a dashed outline and keep their label; put the reason in a `caption` beside them. Pass `busy` while signing: it blocks clicks and shows a dashed working state. Never two `primary` buttons on one screen.
