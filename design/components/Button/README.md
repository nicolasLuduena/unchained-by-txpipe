The action button in four variants. `primary` is the one `ember` element on a screen: the fill, the sale, the signature. `secondary` is a `brand` outline for the alternative path. `ghost` is text-only for low-stakes actions in a row. `danger` is reserved for revoke and cancel.

Provide the label as children, as a verb in the user's words: "Confirmar venta", "Cancelar orden", "Revocar poder". Pass `size="lg"` for the sheet's confirm button (48px). Never two `primary` buttons on one screen. Disabled buttons keep their label; put the reason in a `caption` next to them.
