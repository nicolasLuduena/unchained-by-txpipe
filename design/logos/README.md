# Logos

Nine SVG files, all outlines, no live text, no gradients. The mark is an H: two square bars, the two verified holders, joined by a perforation instead of a crossbar. The left bar is indigo, the right bar is madder.

Screens are light, so the default files are drawn for plaster and paper. The `-reverse` files are plaster, for indigo and other dark grounds.

| File | Use |
| --- | --- |
| `handoff-lockup-horizontal.svg` | Default, on plaster. Headers and documents. Minimum 96px wide. |
| `handoff-lockup-horizontal-reverse.svg` | Same lockup in plaster, for indigo and dark grounds. |
| `handoff-lockup-stacked.svg` | Square spaces, slides, social avatars. |
| `handoff-mark.svg` | Mark alone when the name is already on screen. Minimum 24px. |
| `handoff-mark-mono.svg` | Single indigo, for one-ink use. |
| `handoff-mark-reverse.svg` | Single plaster, for indigo and dark grounds. |
| `handoff-wordmark.svg` | Wordmark alone in indigo. Rare; prefer a lockup. |
| `handoff-wordmark-reverse.svg` | Wordmark alone in plaster. |
| `handoff-app-icon.svg` | 128px plaster square with the mark. Favicon and app tile. |

The wordmark is Barlow Condensed Bold, uppercase, converted to outlines. Colors in the files: indigo #2b2f7f, madder #b23a65, plaster #f2f0ee.

Clear space is one bar width on every side. Never recolor, rotate, outline or add effects.
